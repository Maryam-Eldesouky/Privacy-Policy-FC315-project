# Privacy-Policy-FC315-project
1. What this project does

Almost nobody reads privacy policies. This project measures two things for a sample of services used in Saudi Arabia:

How long and how hard each policy is to read. We calculate word count, reading level and estimated reading time with a Python script.
Whether each policy clearly answers the questions that matter to users. We score every policy against a fixed checklist (for example: does it state how long data is kept, who it is shared with, and how to delete it).

We then compare results by sector (for example food delivery, shopping, government).

All policies we used are published, public documents. We did not contact any company, and we report results by sector, not as a ranking of named companies.
